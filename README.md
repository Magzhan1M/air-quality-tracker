# Air Quality Tracker

A mobile app to monitor real-time air quality and give users health advice based on pollution levels.

## Features
- Live air quality map (PM2.5, PM10, etc.)
- Location-based pollution levels
- Health recommendations
- User-friendly interface

## ⚙️ Built With
- No-code platform: [Thunkable](https://thunkable.com) 
- Open data API for air quality: [Openweathermap] (https://openweathermap.org), [Weatherbit] (https://www.weatherbit.io)
- Visual design with built-in Thunkable UI components
